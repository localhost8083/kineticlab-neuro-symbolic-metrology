Audit of 9 Critical Technical & Mathematical Failures

This section presents interactive visual diagnostics for all nine optical, computer vision, and numerical failure modes identified during the technical audit of the Version 1.0 specification.

Failure Mode 1 Stage 2 Calibration

Axis-Aligned Bounding Box Tilt Bias

Standard SAM bounding boxes expand under in-plane card tilt $\alpha$, overestimating pixel width: $W_{\text{AABB}} = L_{\text{px}}\cos\alpha + H_{\text{px}}\sin\alpha$.

Card Tilt Angle (α): 10°
AABB Width Overestimate: +9.43%
Systematic Error in g: -8.62%
✓ Fix: Mask contour PCA / rotated-rectangle (minAreaRect) scale recovery.
Failure Mode 2 Stage 2 Geometry

Perspective Parallax Depth Offset

When the pendulum swings at distance $\Delta Z$ in front of a wall-mounted card, pinhole projection overestimates distances in the motion plane.

Bob Clearance (ΔZ): 3.0 cm
Scale Inflation: +5.00%
Uncorrected g Value: 10.30 m/s²
✓ Fix: Dual-scale cross-check via $L_{\text{ruler}} / R_{\text{px}}$ and sphere mask depth anchoring.
Failure Mode 3 Stage 4 Pivot Fit

Short-Arc Algebraic Circle Fit

Kåsa algebraic circle fitting on narrow trajectory arcs ($\theta_0 < 25^\circ$) pulls the pivot downward, introducing false 2nd-harmonic distortion.

Kåsa Radius Error: -4.8% (Underfit)
Taubin SVD Error: < 0.1%
Apex Constraint: x_pivot = x_apex
✓ Fix: Taubin SVD initialization coupled with Levenberg-Marquardt vertical symmetry penalty.
Failure Mode 4 Stage 0 Ingest

VFR Hardware Timestamp Corruption

Smartphones record video with Variable Frame Rate (VFR). Forcing constant FPS conversion drops frames and distorts natural period $T$.

Nominal Header: 30.00 fps
True VFR Average: 29.55 fps
Uncorrected g Bias: +3.05%
✓ Fix: Extract exact hardware presentation timestamps (pkt_pts_time) via ffprobe.
Failure Mode 5 Stage 3 Tracking

Bounding Box Centroid Quantization

Inclusive bounding box edges flicker due to motion blur. Area spatial moment centroids average over ~1,960 mask pixels.

Box Corner Jitter: ± 1.20 px
Sub-Pixel Moment Jitter: ± 0.04 px
Noise Reduction Factor: 30× Gain
✓ Fix: Decode SAM 3.1 1-bit RLE masks and compute spatial moment sub-pixel centroids.
Failure Mode 6 Stage 5 Solver

Discontinuous Coulomb Friction Chattering

Discontinuous $\operatorname{sgn}(\dot{\theta})$ in pivot friction causes RK45 adaptive step size collapse ($\Delta t \to 10^{-12}\text{s}$) at turnaround points.

Discontinuous sgn(): Stalls Solver (12s CPU)
Smooth tanh(ω / 10⁻³): Fast Clean Step (0.04s)
✓ Fix: Replace $\operatorname{sgn}(\dot{\theta})$ with continuously differentiable $C^\infty$ hyperbolic tangent regularization.
Failure Mode 7 Stage 5 Optimization

Multi-Start Local Minima Traps

Blind grid searches over non-convex ODE residual space require 20+ integrations per candidate model, running the risk of phase-slipped convergence.

Blind Multi-Start: 25 Iterations (2.4s)
FFT Spectral-Hilbert: 5-8 Iterations (0.12s)
✓ Fix: Analytical FFT warm-starting locks initial $\Omega_0^{(0)}$ within 0.05% inside the global convex basin.
Failure Mode 8 Stage 6 Statistics

Autocorrelated Residual Underestimation

High-frame-rate video tracking exhibits lag-1 autocorrelation ($\rho_1 \approx 0.6$). Standard Ordinary Least Squares understates uncertainty by up to 5×.

Standard OLS CI: ± 0.02 m/s² (Too Narrow)
Newey-West HAC CI: ± 0.09 m/s² (Rigorous)
✓ Fix: Newey-West HAC sandwich covariance matrix and Moving-Block Bootstrap.
Failure Mode 9 Stage 3 Systems

3-Run SAM 3.1 Latency & Credit Exhaustion

Running SAM 3.1 video segmentation three times sequentially per live user request triples execution latency (>36s) and triples API costs.

Sequential 3-Run Latency: 38.4s / $0.108
Single-Run Live Mode: 12.8s / $0.036
✓ Fix: Decouple Live Mode (confidence-weighted propagation) from Benchmark Mode (3-run empirical).
