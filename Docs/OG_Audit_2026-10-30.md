#### [MAJOR-7] Server Security: Cross-Site Request Forgery (CSRF) & DNS Rebinding on `127.0.0.1:8137` Can Trigger Paid `sam-3.1` API Calls and 64 MiB Disk Writes from Any Browser Tab
- **Evidence:** `kineticlab/ui/server.py:466-495`, `522-648`.
- **Failure Scenario:**
  1. Any webpage visited while `kineticlab serve` is running with `MODEL_API_KEY` set can fire `fetch("http://127.0.0.1:8137/api/live", {method: "POST", body: formData, mode: "no-cors"})`, burning paid Meta `sam-3.1` quota and writing 64 MiB files to `uploads/` and `live_out/`.
